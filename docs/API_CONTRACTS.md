# API contracts

Base URL: `/api`

| Method | Path | Purpose |
| --- | --- | --- |
| GET | `/health` | Check API availability |
| GET | `/invoices` | List invoices |
| POST | `/invoices` | Create invoice |
| GET | `/analytics/leaks` | Summarize leakage |
| POST | `/routes/compare` | Compare routes |
| POST | `/ai/chat` | Ask AI assistant |
